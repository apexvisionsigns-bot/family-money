# Family Money
Next.js + Supabase app: accounts, income/expenses, reports, shared schedule, dreams.

1. Run `supabase/schema.sql` in the Supabase SQL Editor.
2. Copy `.env.example` to `.env.local`, fill in your Supabase URL + anon key.
3. `npm install` then `npm run dev`.
4. On Vercel add the same two environment variables.
